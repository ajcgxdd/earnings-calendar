# Indian Earnings Calendar

A simple React calendar for tracking upcoming earnings results across Indian equities.

## Features

- Month and week views
- Previous, next, and today navigation
- Earnings data displayed on calendar dates

## Getting started

```bash
npm install
npm run dev
```

Open the local URL shown in the terminal.

## Other commands

```bash
npm run build   # Create a production build
npm run preview # Preview the production build
npm run lint    # Check the code
```
